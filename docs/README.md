# Actividades del curso: MLOps con Metaflow y MLflow

Serie de cuatro actividades con un hilo conductor común. Las actividades 1 a 3 sustentan la actividad 4, que integra el sistema completo.

| # | Actividad | Módulo | Entregable principal |
|---|-----------|--------|----------------------|
| 1 | [Fundamentos, versionamiento y tracking](./actividad-1.md) | Módulo 1 | Repositorio Git + memoria 1 |
| 2 | [Pipeline y empaquetado](./actividad-2.md) | Módulo 2 | Repositorio + memoria 2 |
| 3 | [Monitoreo, CI/CD y gobernanza](./actividad-3.md) | Módulo 3 | Repositorio con CI + memoria 3 |
| 4 | [Sistema end-to-end](./actividad-4.md) | Integración | Repositorio integrado + presentación de slides |

Las fechas de sesiones y entregas están en el [calendario del curso](./calendario.md).

## Supuestos generales

- **Stack núcleo:** Metaflow (orquestación de pipelines) y MLflow (tracking, registro y servicio de modelos).
- **Herramientas complementarias del temario:** Evidently AI, GitHub Actions o Jenkins y Docker se usan solo donde el módulo las exige.
- **Datos:** sintéticos y generados por un script con semilla fija. Los estudiantes construyen el modelo desde cero, sin modelos preentrenados ni AutoML.

## Memoria de actividad

Cada actividad entrega una memoria con la estructura de [plantilla-memoria.md](./plantilla-memoria.md).
